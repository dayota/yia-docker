# U54 — Traiter un changement de nom de projet

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Modifier `project.name` change l'identité Compose. Yia refuse donc `make update`
afin de ne pas abandonner les ressources sous l'ancien nom. Rétablir le nom,
inventorier et sauvegarder, puis suivre une migration explicite couvrant les
deux identités. Voir [T07](./t07.md).
