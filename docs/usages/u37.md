# U37 — Construire ou reconstruire les images

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`make build` utilise le cache et ne démarre pas nécessairement les services.
`make rebuild` reconstruit sans cache, recrée les containers et attend leurs
healthchecks. Les deux exigent une génération à jour et conservent les volumes.
Utiliser `rebuild` pour diagnostiquer une image, pas pour corriger une donnée
applicative.
