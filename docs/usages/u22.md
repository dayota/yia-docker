# U22 — Exécuter une commande de paquet ponctuelle

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Utiliser l'identifiant applicatif, jamais le nom de container Compose. Pour U16 :

```bash
make exec SERVICE=frontend CMD="pnpm run lint"
make exec SERVICE=frontend CMD="pnpm run test"
make exec SERVICE=frontend CMD="pnpm install --lockfile-only"
```

Les scripts `lint` et `test` doivent exister dans le `package.json` du projet ;
ils ne sont pas inventés par Yia. Pour les variantes U18, remplacer `pnpm` par
`npm` ou `yarn` et employer leur syntaxe. La génération volontaire d'un lockfile
modifie les sources montées : examiner ensuite `git diff` et ne pas conserver
un fichier appartenant à un autre gestionnaire.

Pour une exploration interactive :

```bash
make shell SERVICE=frontend
```

Quitter le shell sans modifier `.yia/` ni `.yia-runtime/`. Les commandes
répétables doivent rester dans les scripts du projet plutôt que dans une suite
de manipulations manuelles.
