# U30 — Préserver les données PostgreSQL

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Créer une preuve, appliquer chaque opération, puis relire la ligne :

```bash
make exec SERVICE=postgres CMD="psql -U yia_app -d yia_app -c 'CREATE TABLE IF NOT EXISTS yia_probe (value text)'"
make exec SERVICE=postgres CMD="psql -U yia_app -d yia_app -c \"INSERT INTO yia_probe VALUES ('kept')\""
make down
make up
make restart
make update
make rebuild
make reset
make destroy
make update
make exec SERVICE=postgres CMD="psql -U yia_app -d yia_app -tAc 'SELECT value FROM yia_probe'"
```

La dernière commande doit retourner `kept`. `down`, `restart`, `update`,
`rebuild`, `reset` et `destroy` conservent les volumes. Seul U33 les supprime
explicitement. Une sauvegarde U31 reste recommandée avant une migration métier.
