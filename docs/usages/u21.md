# U21 — Utiliser Node 22 et Node 24 simultanément

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Partir de U20 et attribuer Node 22 à `admin` :

```diff
   admin:
     runtime:
-      node: "24"
+      node: "22"
       package_manager: pnpm
```

```bash
make update
make ps FORMAT=json
make exec SERVICE=admin CMD="node --version"
make exec SERVICE=frontend CMD="node --version"
```

Les services deviennent `node-22-admin` et `node-24-frontend`. Ils utilisent
deux images de base et conservent chacun leurs dépendances. U25 exécute cette
topologie avec PHP et PostgreSQL dans le même monorepo.
