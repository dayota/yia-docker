# U42 — Nettoyer et reconstruire le runtime généré

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```bash
make clean
make generate
make config
make update
```

`clean` supprime uniquement `.yia-runtime/`. `generate` le reconstruit sans
Docker, puis `update` remet l'environnement en convergence. Sources, fichiers
humains, `.env` et volumes restent intacts. Voir [T05](./t05.md).
