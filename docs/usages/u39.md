# U39 — Ouvrir un shell ou exécuter une commande

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```bash
make shell SERVICE=api
make exec SERVICE=api CMD="php --version"
make exec SERVICE=frontend CMD="node --version"
make exec SERVICE=postgres CMD="psql --version"
```

`exec` est préférable pour une action reproductible ; `shell` sert à
l'exploration. Yia résout l'application vers son runtime et son répertoire de
travail. Ne modifier ni `.yia/` ni les artefacts générés depuis le container.
