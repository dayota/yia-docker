# U06 — Créer un projet minimal sans application ni service

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Fichiers minimaux

```text
minimal/
├── .yia/
├── .env.example
├── .gitignore
├── Makefile
└── yia.yml
```

Le Makefile est celui de U24. `.env.example` peut contenir seulement un
commentaire, car Yia n'exige ici aucune variable. Le fichier `yia.yml` complet
est :

```yaml
version: 1
project:
  name: minimal
environment:
  domain: minimal.localhost
applications: {}
```

Initialiser puis faire converger :

```bash
make init
make validate
make config
make generate
make update
make update
```

Les deux dernières commandes doivent annoncer `aucun service déclaré`; elles
n'ont pas besoin du daemon Docker. Aucun container, réseau ou volume n'est
créé. La documentation projet et le runtime généré existent néanmoins, et le
second passage ne modifie aucun fichier. `make clean` peut supprimer uniquement
`.yia-runtime/`, que `make generate` reconstruit ensuite à l'identique.
