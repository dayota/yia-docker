# U43 — Réinitialiser sans perdre les données

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`make reset` arrête l'environnement, supprime le runtime généré, le régénère,
reconstruit et redémarre. Les containers peuvent changer d'identifiant, mais les
volumes doivent rester les mêmes. Vérifier une donnée témoin comme dans U30 et
les healthchecks après l'opération.
