# U19 — Exécuter un worker Node sans HTTP

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Configuration et processus

Omettre `web`, mais conserver le script `dev` :

```yaml
version: 1
project:
  name: node-worker
environment:
  domain: node-worker.localhost
applications:
  worker:
    type: node
    path: apps/worker
    runtime:
      node: "24"
      package_manager: pnpm
    framework:
      name: nuxt
      version: 4
```

Pour une sonde minimale, `package.json` déclare
`"dev": "node worker.mjs"` et `worker.mjs` conserve un processus actif, par
exemple avec `setInterval(() => {}, 60_000)`. Après `make update`, seul
`node-24-worker` est attendu : aucun Apache et aucune URL.

```bash
make exec SERVICE=worker CMD="node --version"
make logs SERVICE=worker
make ps FORMAT=json
```

Le healthcheck contrôle l'existence du processus principal, puisqu'aucun port
n'est déclaré. Un script qui se termine immédiatement rend donc le service
dégradé ; consulter [T01](./t01.md).
