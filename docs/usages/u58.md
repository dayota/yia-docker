# U58 — Exposer une application ZendFramework en PHP 8.2

[← Index des cas d’usage](./index.md) · [U57 — Laminas](./u57.md)

Partir d’une application ZendFramework existante dont les dépendances et le
code ont été vérifiés avec PHP 8.2. Yia fournit PHP-FPM et le routage HTTP ;
il ne migre pas les paquets ZendFramework vers Laminas. Le projet ZendFramework
ayant été transféré à Laminas, cette compatibilité dépend du projet consommateur
et de son `composer.lock`.

```text
.
├── .yia/
├── Makefile
├── yia.yml
├── .env.example
└── apps/web/
    ├── composer.json
    ├── composer.lock
    └── public/index.php
```

```yaml
version: 1
project:
  name: zend-web
environment:
  domain: zend-web.localhost
applications:
  web:
    type: php
    path: apps/web
    runtime:
      php: "8.2"
    framework:
      name: zendframework
    web:
      hostname: zend-web.localhost
      public_directory: public
```

Documenter les seules clés locales nécessaires dans `.env.example`, sans
valeur secrète. Les renseigner dans `.env` si l’application en a besoin.

```bash
make init
make validate
make update
make exec SERVICE=web CMD="composer install"
make exec SERVICE=web CMD="composer check-platform-reqs"
curl --fail --resolve zend-web.localhost:80:127.0.0.1 http://zend-web.localhost/
make doctor FORMAT=json
make update
```

La requête doit retourner la page attendue et les contrôles Composer confirmer
la compatibilité PHP 8.2. Les services sont `apache` et `php-8.2`. Le second
`make update` doit conserver container et volume `php-web-vendor`. Terminer par
`make down` ou `make destroy` ; les dépendances en volume restent disponibles.
