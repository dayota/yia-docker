# U14 — Gérer les dépendances Composer

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Composer est disponible dans toutes les images PHP Yia. Depuis U08 :

```bash
make exec SERVICE=api CMD="composer validate"
make exec SERVICE=api CMD="composer install --no-interaction"
```

`composer.json` et `composer.lock` appartiennent aux sources du projet.
`vendor/` est monté dans le volume nommé `php-api-vendor` et n'est donc pas
écrit sur l'hôte. `install` respecte le lockfile. Pour modifier volontairement
les versions résolues :

```bash
make exec SERVICE=api CMD="composer update --no-interaction"
git diff -- apps/api/composer.lock
```

Le nouveau lockfile est une modification humaine à relire et versionner ; Yia
ne le remplace jamais silencieusement. Les identifiants de dépôts Composer
privés restent des secrets locaux et ne doivent entrer ni dans `yia.yml`, ni
dans ce guide, ni dans les sorties machine.
