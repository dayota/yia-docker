# U27 — Démarrer PostgreSQL seul

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```yaml
version: 1
project:
  name: database
environment:
  domain: database.localhost
services:
  postgres:
    enabled: true
    version: "18"
applications: {}
```

Créer `.env` depuis `.env.example` comme dans U24 et renseigner un mot de passe
local non vide, puis :

```bash
make init
make update
make exec SERVICE=postgres \
  CMD="psql -U yia_app -d yia_app -tAc 'SELECT 1'"
make doctor FORMAT=json
```

Seul `postgres` est créé, sans port publié. Le healthcheck utilise `pg_isready`
et la requête retourne `1`. Une absence de variable ou un service unhealthy se
traite avec [T01](./t01.md).
