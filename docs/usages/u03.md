# U03 — Ajouter Yia à un nouveau dépôt

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Créer et épingler le sous-module

```bash
mkdir full
cd full
git init
git submodule add "<URL-DU-DÉPÔT-YIA>" .yia
git -C .yia checkout "<COMMIT-YIA-VALIDÉ>"
cp .yia/templates/project/Makefile ./Makefile
```

Les valeurs entre chevrons doivent être remplacées par l'URL autorisée et le
commit choisi par l'équipe. Le dépôt parent versionne `.gitmodules` et le
gitlink `.yia` : il épingle ainsi Yia, même si la branche distante évolue.
Ne jamais écrire de configuration ou de donnée propre au projet dans `.yia/`.

Créer ensuite à la racine `yia.yml`, `.env.example` et `.gitignore`. Pour une
première prise en main sans Docker, utiliser les contenus de [U06](./u06.md). Pour
le projet full stack de référence, utiliser ceux de [U24](./u24.md). Contrôler enfin
le montage avant toute initialisation :

```bash
git submodule status .yia
make check-install
git status --short
```

Cloner ultérieurement le dépôt consommateur avec ses sous-modules :

```bash
git clone --recurse-submodules "<URL-DU-PROJET>"
```

ou, après un clone ordinaire :

```bash
git submodule update --init --recursive
```
