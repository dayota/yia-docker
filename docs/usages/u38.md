# U38 — Lire les logs

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```bash
make logs
make logs SERVICE=api
make logs SERVICE=api FOLLOW=1
```

Sans `FOLLOW=1`, la commande affiche puis quitte. `SERVICE` accepte une
application ou un service logique. Le suivi est volontaire et s'arrête avec
Ctrl-C sans arrêter le container. Ne publier aucun log contenant un secret.
