# U01 — Vérifier les prérequis

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Objectif et exécution

Depuis un projet qui contient déjà le sous-module `.yia/` et le Makefile proxy,
effectuer un contrôle strictement non modifiant :

```bash
make check-install
```

La commande vérifie Python 3.12 ou supérieur, Git, Make, le client Docker, le
plugin Docker Compose, l'accès au daemon et, depuis un projet consommateur, la
présence du sous-module `.yia/`. Chaque contrôle est marqué `ok` ou `error` et
la commande retourne un code non nul dès qu'un prérequis manque.

Elle n'installe rien, ne démarre aucun container et ne modifie aucun fichier.
Corriger seulement la dépendance signalée, relancer le contrôle, puis poursuivre
avec U03 ou U04. Pour distinguer client Docker absent, daemon inaccessible et
permissions insuffisantes, consulter [T01](./t01.md).
