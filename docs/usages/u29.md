# U29 — Exposer PostgreSQL à l'hôte

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Ajouter uniquement lorsque l'accès depuis un client local est requis :

```diff
   postgres:
     enabled: true
     version: "18"
+    expose: true
```

Après `make update`, PostgreSQL publie `5432:5432` :

```bash
psql --host=127.0.0.1 --port=5432 --username=yia_app --dbname=yia_app
```

Le client lit le mot de passe de façon interactive ou depuis un mécanisme local
approprié, jamais depuis la ligne de commande versionnée. Vérifier auparavant
que le port est libre et que l'exposition est acceptable sur la machine. La
valeur par défaut `expose: false` reste préférable.
