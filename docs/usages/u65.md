# U65 — Configurer les conteneurs pour Traefik externe

[← Index](./index.md) · [Contrat](../configuration.md#traefik-externe-optionnel-en-v2)

Prérequis : Docker/Compose, un sous-module `.yia/` installé et un Traefik externe
déjà connecté au réseau `proxy`, avec provider Docker et entrypoint `web`.
Le propriétaire de Traefik crée et gère ce réseau ; Yia ne le crée pas.
Le provider doit de préférence désactiver l'exposition par défaut et limiter
les conteneurs découverts. Yia impose néanmoins `traefik.enable=false` à tous
ses conteneurs non autorisés.

## 1. Préparer le projet

```text
traefik-demo/
├── .yia/
├── yia.yml
└── sources/api/public/index.php
```

`sources/api/public/index.php` :

```php
<?php
echo 'Traefik → Apache → PHP';
```

`yia.yml` :

```yaml
version: 2
project:
  name: traefik-demo
environment:
  domain: traefik-demo.localhost
applications:
  api:
    type: php
    path: sources/api
    source: {type: linked}
    runtime: {php: "8.4"}
    web:
      hostname: api.traefik-demo.localhost
      public_directory: public
traefik:
  network: proxy
  containers:
    apache:
      expose: true
      labels:
        traefik.http.routers.traefik-demo-api.rule: Host(`api.traefik-demo.localhost`)
        traefik.http.routers.traefik-demo-api.entrypoints: web
        traefik.http.routers.traefik-demo-api.service: traefik-demo-apache
        traefik.http.services.traefik-demo-apache.loadbalancer.server.port: "80"
```

Aucune variable ni secret n'est nécessaire dans `.env`. Une fixture complète
est fournie dans `tests/projects/traefik/`. Employer des noms de routers et de
services uniques entre projets. Chaque hostname doit correspondre à un vhost
Apache ; les labels ne remplacent pas le bloc applicatif `web`.

## 2. Initialiser et vérifier

```bash
make -f .yia/Makefile init
make validate FORMAT=json
make doctor FORMAT=json
make update
make update
make status FORMAT=json
```

Avant démarrage, `doctor` peut signaler des conteneurs arrêtés ; le check
`traefik-network` doit être `ok`. Si `proxy` n'existe pas, demander au propriétaire
du proxy de le préparer : `update` échoue, sans création automatique.

Lorsque le Traefik externe écoute sur le port hôte 80, ouvrir
`http://api.traefik-demo.localhost` : la réponse attendue est
`Traefik → Apache → PHP`. Apache écoute seulement dans Docker, sans port hôte.
PHP-FPM reste sur le réseau privé. Le second `update` conserve les artefacts
et le conteneur Apache inchangés.

## 3. Déclarer une exposition de service privé

Les labels ciblent les noms logiques Compose, pas les noms physiques de
conteneurs. Un service absent ou désactivé est refusé.

Pour exposer explicitement OpenBao, déjà déclaré dans `services` comme dans
[U64](./u64.md), ajouter sous `traefik.containers` :

```yaml
openbao:
  expose: true
  labels:
    traefik.http.routers.traefik-demo-bao.rule: Host(`bao.traefik-demo.localhost`)
    traefik.http.routers.traefik-demo-bao.entrypoints: web
    traefik.http.routers.traefik-demo-bao.service: traefik-demo-bao
    traefik.http.services.traefik-demo-bao.loadbalancer.server.port: "8200"
```

Cette décision ajoute OpenBao au réseau partagé. Elle ne publie pas de port
hôte, n'active pas son UI, ne l'initialise pas et ne le déverrouille pas.
Ses clés et tokens restent hors de Yia. Sans `expose: true`, ces labels de
routage sont refusés et le coffre reste privé.

Redis et PostgreSQL utilisent des routes **TCP**, dont les entrypoints doivent
être préparés sur le Traefik externe ; une route HTTP ne convient pas. Les
runtimes applicatifs ne peuvent pas être exposés directement : les applications
restent servies par Apache. L'autorisation Traefik est indépendante d'un éventuel
`services.<service>.expose` de publication directe sur l'hôte.

## 4. TLS, middlewares et secrets

Les valeurs de labels sont des chaînes littérales : ni `$`, ni interpolation
de `.env`, ni credentials inline. Référencer les middlewares et configurations
TLS gérés par le proxy externe. Les entrypoints, certificats et resolvers
ne sont pas créés par Yia. `status` continue d'afficher les URLs HTTP des blocs
`web`, sans interpréter des labels TLS libres.

Les labels `traefik.enable` et `traefik.docker.network` sont imposés par Yia.
Les autres labels restent à la charge de l'opérateur ; `validate` ne remplace
pas la validation du provider Traefik. Aucun secret ne doit être placé dans
un label, même si son nom ne permet pas à Yia de le détecter.

## 5. Nettoyage et dépannage

```bash
make logs SERVICE=apache
make doctor FORMAT=json
make down
```

`down` conserve les volumes et le réseau externe. `destroy` conserve aussi
les volumes ; seul `destroy-data YES=1` supprime les volumes du projet après
confirmation explicite, sans supprimer le réseau partagé ni le proxy externe.

Un HTTP 404 peut venir d'une règle Traefik ou d'un hostname Apache incorrect ;
un 502 d'un mauvais réseau ou port cible. Consulter les logs du proxy via son
propriétaire et ceux d'Apache via Make. Voir [T01](./t01.md) et [T05](./t05.md).
