# U18 — Choisir npm, pnpm ou Yarn

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

U16 est l'exemple principal pnpm. Le gestionnaire peut être omis car `pnpm` est
la valeur par défaut, mais le déclarer rend l'exemple plus lisible. Conserver un
seul lockfile cohérent avec ce choix :

| Gestionnaire | `package_manager` | Lockfile attendu |
|---|---|---|
| pnpm | `pnpm` | `pnpm-lock.yaml` |
| npm | `npm` | `package-lock.json` ou `npm-shrinkwrap.json` |
| Yarn Classic | `yarn` | `yarn.lock` |

Variante npm :

```diff
     runtime:
       node: "24"
-      package_manager: pnpm
+      package_manager: npm
```

Variante Yarn :

```diff
     runtime:
       node: "24"
-      package_manager: pnpm
+      package_manager: yarn
```

Au démarrage, Yia installe les dépendances avant `dev`. Un lockfile existant est
utilisé en mode figé et doit rester inchangé. Sans lockfile, Yia n'en crée pas
silencieusement. Pour en produire ou mettre à jour un volontairement, exécuter
la commande du gestionnaire via U22, relire le diff, puis versionner le fichier
avant le prochain `make update`.
