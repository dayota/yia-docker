# T03 — Configuration `yia.yml` invalide

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Exécuter `make validate FORMAT=json` et lire le code `YIA_CONFIG_INVALID` ainsi
que le chemin structuré. Corriger la propriété fautive dans `yia.yml`, ou le
fichier applicatif explicitement cité, puis relancer la validation. Les fautes
inconnues ne sont jamais ignorées. Ne modifier ni le schéma embarqué ni le
runtime généré pour contourner l'erreur.
