# U12 — Utiliser PHP 8.2 et PHP 8.4 simultanément

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

U25 fournit la configuration complète : `legacy` utilise PHP 8.2 et `api`
utilise PHP 8.4. Pour un projet uniquement PHP, supprimer les deux applications
Node et, si elle est inutile, la section PostgreSQL de cet exemple.

```bash
make validate
make update
make ps FORMAT=json
make exec SERVICE=legacy CMD="php --version"
make exec SERVICE=api CMD="php --version"
```

La liste doit contenir `apache`, `php-8.2` et `php-8.4`. Les deux commandes
retournent leurs versions respectives et les hostnames restent routés vers le
bon runtime. Les images, pools et volumes des deux versions sont indépendants.
