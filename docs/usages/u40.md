# U40 — Observer l'environnement

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`make ps FORMAT=json` décrit les containers réels ; `make status FORMAT=json`
combine validité, génération et état ; `make doctor FORMAT=json` ajoute les
prérequis et diagnostics. Les listes sont déterministes et sans secret. Utiliser
les codes de sortie et champs JSON en automatisation, sans parser les messages
humains. Voir [T01](./t01.md) et [T05](./t05.md).
