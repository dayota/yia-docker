# U45 — Automatiser les contrôles en CI locale

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```bash
make validate FORMAT=json
make status FORMAT=json
make ps FORMAT=json
make doctor FORMAT=json
make version FORMAT=json
```

Ces cinq commandes garantissent un JSON déterministe sur stdout et un code de
sortie stable. Ne demander `FORMAT=json` à aucune autre cible et ne parser ni
l'ordre visuel ni le texte humain. La CI peut valider sans démarrer ; les autres
contrôles reflètent l'état réellement disponible.
