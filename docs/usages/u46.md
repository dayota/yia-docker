# U46 — Vérifier la version de l'environnement

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`make version FORMAT=json` fournit la version Yia, le commit Git disponible,
les versions des schémas et celles de Python, Git, Make, Docker et Compose. Il
ne contacte pas le daemon. Comparer aussi `git submodule status .yia` au commit
attendu avant une mise à jour ou dans un rapport de CI.
