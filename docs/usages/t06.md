# T06 — Migration de schéma requise

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Avec `YIA_MIGRATION_REQUIRED`, noter les versions indiquées et arrêter les
tentatives de convergence. Sauvegarder les données, lire les notes de la version
Yia ciblée et appliquer sa procédure inspectable. Une suppression de l'état ou
une réinitialisation forcée n'est pas une migration. Valider ensuite deux
`make update` et `make doctor`.
