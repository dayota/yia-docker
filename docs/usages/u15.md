# U15 — Exécuter les commandes d'un framework PHP

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`SERVICE` accepte l'identifiant d'application et résout le runtime partagé tout
en sélectionnant son répertoire de travail. Dans une application Laravel réelle :

```bash
make exec SERVICE=api CMD="php artisan about"
make exec SERVICE=api CMD="php artisan migrate:status"
```

Dans une application Symfony réelle :

```bash
make exec SERVICE=legacy CMD="php bin/console about"
make exec SERVICE=legacy CMD="php bin/console doctrine:migrations:status"
```

Ces exécutables ne sont pas présents dans les sondes minimales du guide : ils
proviennent du framework installé par le projet. Préférer `make exec` aux appels
directs à `docker compose`, afin que la résolution logique reste stable. Les
commandes de migration peuvent modifier la base ; lire leur plan et sauvegarder
les données selon U31 avant une opération risquée.
