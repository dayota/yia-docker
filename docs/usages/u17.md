# U17 — Utiliser Node 22

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Dans U16, changer uniquement la version explicite :

```diff
     runtime:
-      node: "24"
+      node: "22"
       package_manager: pnpm
```

Après `make update`, le service devient `node-22-frontend` et
`make exec SERVICE=frontend CMD="node --version"` doit annoncer Node 22. Le
hostname, le port privé, le gestionnaire et le volume de dépendances ne changent
pas. Revenir à Node 24 constitue une nouvelle convergence explicite, pas une
mise à niveau automatique.
