# U59 — Exposer une API FastAPI en Python 3.12

[← Index des cas d’usage](./index.md)

Créer ces fichiers dans un projet consommateur Yia. `requirements.txt` appartient
à l’application ; la version de chaque paquet doit y être fixée. Le point
d’entrée HTTP est l’objet `app` de `main.py`.

```text
.
├── .yia/
├── Makefile
├── yia.yml
├── .env.example
└── apps/api/
    ├── main.py
    └── requirements.txt
```

`apps/api/main.py` :

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "ok"}
```

`apps/api/requirements.txt` :

```text
fastapi==0.115.12
uvicorn==0.34.2
```

`yia.yml` :

```yaml
version: 1
project:
  name: fastapi-api
environment:
  domain: fastapi-api.localhost
applications:
  api:
    type: python
    path: apps/api
    runtime:
      python: "3.12"
    framework:
      name: fastapi
    web:
      hostname: api.fastapi-api.localhost
      port: 8000
```

Laisser `.env.example` vide pour cet exemple ; renseigner `.env` si l’API a
besoin de variables locales.

```bash
make init
make validate
make update
curl --fail --resolve api.fastapi-api.localhost:80:127.0.0.1 http://api.fastapi-api.localhost/
make exec SERVICE=api CMD="python --version"
make doctor FORMAT=json
make update
```

La requête doit renvoyer `{"message":"ok"}` et Python annoncer 3.12. Apache
est seul publié sur le port 80 ; `python-3.12-api` écoute sur le port privé
8000. Les paquets sont installés au démarrage dans `python-api-venv`, volume
distinct des sources. Le second `make update` conserve le container et le
volume. `make down` ou `make destroy` arrête l’environnement sans supprimer ce
volume.
