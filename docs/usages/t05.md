# T05 — Runtime généré absent ou obsolète

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`YIA_GENERATION_FAILED` indique que la configuration, le manifeste et
`.yia-runtime/` ne correspondent plus. Exécuter :

```bash
make validate
make generate
make config
make update
```

Si nécessaire, U42 autorise `make clean` car seul le runtime reconstructible est
supprimé. Ne toucher ni aux volumes, ni aux sources, ni à `.env`.
