# U02 — Installer les prérequis sur un système APT

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Objectif et précautions

Cette commande est réservée à une machine sur laquelle `apt-get` est disponible.
Elle affiche les composants concernés puis installe, avec les privilèges root ou
`sudo`, les paquets `docker.io`, `docker-compose-v2`, `git`, `make`, `python3` et
`python3-venv` :

```bash
make install
make check-install
```

`make install` modifie le système, pas le projet applicatif. L'exécuter depuis
le dépôt Yia ou depuis un projet muni du proxy uniquement après avoir accepté
ces paquets et la politique Docker de la machine. La commande est relançable ;
APT laisse les paquets déjà installés dans leur état courant.

Sur un système sans APT, Yia s'arrête avec une erreur explicite au lieu de
tenter une commande d'une autre distribution. Installer alors les dépendances
avec le mécanisme documenté par le système, puis utiliser seulement
`make check-install`. Après installation, le fonctionnement quotidien ne doit
pas nécessiter `sudo` pour chaque commande Docker ; voir [T01](./t01.md) si l'accès
au daemon reste refusé.
