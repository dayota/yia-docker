# U50 — Préserver une documentation humaine

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Ajouter une note sous `.agents/docs/domain/`, exécuter deux `make update`, puis
vérifier qu'elle reste inchangée. Yia peut actualiser les documents dérivés et
sa section gérée dans `AGENTS.md`, jamais le texte humain hors marqueurs. Une
fusion incertaine doit rester explicite.
