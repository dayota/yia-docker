# U20 — Héberger plusieurs applications Node sur la même version

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Le fichier suivant partage l'image Node 24 sans partager les processus :

```yaml
version: 1
project:
  name: node-shared
environment:
  domain: node-shared.localhost
applications:
  admin:
    type: node
    path: apps/admin
    runtime:
      node: "24"
      package_manager: pnpm
    framework:
      name: nuxt
    web:
      hostname: admin.node-shared.localhost
      port: 3000
  frontend:
    type: node
    path: apps/frontend
    runtime:
      node: "24"
      package_manager: pnpm
    framework:
      name: nuxt
    web:
      hostname: node-shared.localhost
      port: 3000
```

Les services sont `apache`, `node-24-admin` et `node-24-frontend`. Le même port
privé peut être utilisé dans les deux containers. Les volumes
`node-admin-modules` et `node-frontend-modules`, les processus, les logs et les
healthchecks restent distincts, tandis que les deux services utilisent la même
image Yia Node 24.
