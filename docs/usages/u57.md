# U57 — Exposer une API Laminas en PHP 8.2

[← Index des cas d’usage](./index.md) · [U08 — routage PHP](./u08.md)

Préparer un projet consommateur Yia avec une application Laminas existante dans
`apps/api`. Son contrôleur frontal doit se trouver dans `apps/api/public/index.php`
et son `composer.json` à la racine de `apps/api` : Yia ne crée pas le code Laminas.

```text
.
├── .yia/
├── Makefile
├── yia.yml
├── .env.example
└── apps/api/
    ├── composer.json
    └── public/index.php
```

```yaml
version: 1
project:
  name: laminas-api
environment:
  domain: laminas-api.localhost
applications:
  api:
    type: php
    path: apps/api
    runtime:
      php: "8.2"
    framework:
      name: laminas
    web:
      hostname: api.laminas-api.localhost
      public_directory: public
```

`.env.example` peut être vide tant que l’application ne réclame pas de variable.
Ne copier dans `.env` que les valeurs locales dont elle a réellement besoin.

```bash
make init
make validate
make update
make exec SERVICE=api CMD="composer install"
curl --fail --resolve api.laminas-api.localhost:80:127.0.0.1 http://api.laminas-api.localhost/
make exec SERVICE=api CMD="php --version"
make doctor FORMAT=json
make update
```

La requête doit retourner la réponse de l’API et `php --version` annoncer PHP
8.2. Les services attendus sont `apache` et `php-8.2`. Le second `make update`
doit conserver le container et `php-api-vendor`. Nettoyer avec `make down` ou
`make destroy` ; ces commandes conservent le volume Composer.
