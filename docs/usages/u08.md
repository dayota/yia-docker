# U08 — Exposer une API Laravel en PHP 8.4

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Configuration de référence PHP

Créer `apps/api/public/index.php` avec la sonde PHP de U24 et, pour une vraie
application Laravel, conserver également son `composer.json` à la racine de
`apps/api`. La configuration Yia complète est :

```yaml
version: 1
project:
  name: php-api
environment:
  domain: php-api.localhost
applications:
  api:
    type: php
    path: apps/api
    runtime:
      php: "8.4"
    framework:
      name: laravel
      version: 13
    web:
      hostname: api.php-api.localhost
      public_directory: public
```

Initialiser, démarrer et vérifier FastCGI :

```bash
make init
make validate
make update
curl --fail --resolve api.php-api.localhost:80:127.0.0.1 \
  http://api.php-api.localhost/
make exec SERVICE=api CMD="php --version"
make exec SERVICE=api CMD="composer --version"
make doctor FORMAT=json
```

Yia crée `apache` et `php-8.4`. Apache est seul publié sur le port 80 et envoie
les fichiers PHP au pool FPM privé de `api`; ni FPM ni Xdebug ne publient de
port. Composer est fourni par l'image PHP. Un second `make update` doit préserver
le container et le volume `php-api-vendor`. Terminer avec `make down` ou
`make destroy`, qui conservent ce volume.

Les variantes PHP 8.2 sont [Laminas](./u57.md) et
[ZendFramework](./u58.md). Une API [FastAPI](./u59.md) utilise le runtime
Python 3.12 et le même point d'entrée Apache.
