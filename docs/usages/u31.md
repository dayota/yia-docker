# U31 — Sauvegarder et restaurer PostgreSQL

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Conserver les sauvegardes dans un répertoire local appartenant au projet et
ignoré par Git :

```bash
mkdir -p .yia-data/backups
make exec SERVICE=postgres \
  CMD="pg_dump -U yia_app -d yia_app --format=custom" \
  > .yia-data/backups/yia_app.dump
test -s .yia-data/backups/yia_app.dump
```

Restaurer dans une base vide ou selon une procédure métier explicitement
acceptée :

```bash
make exec SERVICE=postgres \
  CMD="pg_restore -U yia_app -d yia_app --clean --if-exists" \
  < .yia-data/backups/yia_app.dump
```

`--clean` peut supprimer des objets dans la base cible : vérifier la cible et
la sauvegarde avant cette commande. Les flux passent par l'API Make ; aucun
dump n'est écrit dans `.yia/` ou dans le container. Protéger et chiffrer le
fichier selon la sensibilité des données.
