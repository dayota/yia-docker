# U60 — Exposer une application avec PHP 8.5

[← Index des cas d’usage](./index.md) · [U56 — catalogue des runtimes](./u56.md)

Ce cas utilise le runtime PHP 8.5 avec le routage Apache/FastCGI existant.
Partir d'un projet consommateur Yia et créer les fichiers suivants :

```text
.
├── .yia/
├── Makefile
├── yia.yml
├── .env.example
└── apps/api/
    └── public/index.php
```

`apps/api/public/index.php` :

```php
<?php
header('Content-Type: text/plain; charset=utf-8');
echo 'PHP ' . PHP_VERSION;
```

`yia.yml` :

```yaml
version: 1
project:
  name: php-85
environment:
  domain: php-85.localhost
applications:
  api:
    type: php
    path: apps/api
    runtime:
      php: "8.5"
    web:
      hostname: api.php-85.localhost
      public_directory: public
```

Laisser `.env.example` vide pour cette sonde ; renseigner `.env` si l'application
réelle nécessite des variables locales. Depuis la racine du projet :

```bash
make init
make validate
make update
curl --fail --resolve api.php-85.localhost:80:127.0.0.1 \
  http://api.php-85.localhost/
make exec SERVICE=api CMD="php --version"
make exec SERVICE=api CMD="php-fpm -t"
make doctor FORMAT=json
make update
```

La réponse commence par `PHP 8.5.` ; `php --version` confirme PHP 8.5 et
`php-fpm -t` valide la configuration. Les services sont `apache` et `php-8.5`.
FPM reste sur le réseau privé. Le second `make update` conserve le container
et le volume `php-api-vendor`. Terminer avec `make down` ou `make destroy` ;
ces commandes conservent ce volume.
