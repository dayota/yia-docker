# U35 — Ajouter, retirer ou changer une application

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

En V2, déclarer `source: {type: linked}` pour un dossier local existant hors de
`apps/`, ou `source.type: managed` avec `git.ssh`, `git.branch` et `git.version`
(un tag) pour `apps/<dossier>`. Valider, puis lancer `make update` : Yia clone
la source managed avant de générer l'environnement. Pour un retrait, supprimer le bloc
mais conserver les sources tant que leur suppression n'a pas été décidée
séparément. Compose retire les containers orphelins, jamais leurs volumes. Un
changement de runtime recrée seulement les services affectés. Contrôler le diff
de `.agents/docs/architecture/development-environment.md` et `make ps`.
