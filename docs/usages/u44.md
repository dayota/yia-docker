# U44 — Détruire l'environnement sans détruire les données

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

`make destroy` affiche puis supprime containers, réseau et `.yia-runtime/`. Il
conserve explicitement tous les volumes. `make update` peut ensuite reconstruire
l'environnement et retrouver la donnée témoin U30. Pour supprimer aussi les
données, seule la procédure distincte U33 est autorisée.
