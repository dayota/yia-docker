# T02 — Port 80 ou hostname indisponible

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Tester d'abord le routage sans dépendre du DNS :

```bash
curl --fail --resolve full.localhost:80:127.0.0.1 http://full.localhost/
getent hosts full.localhost
make ps FORMAT=json
make logs SERVICE=apache
```

Si le port 80 est occupé, identifier son propriétaire avec les outils du
système et demander son arrêt ou sa reconfiguration ; Yia ne le fait pas. Si
`--resolve` fonctionne, corriger seulement la résolution hôte. Si le mauvais
site répond, corriger `web.hostname`, puis `make validate` et `make update`.
