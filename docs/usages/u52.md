# U52 — Mettre à jour le sous-module Yia

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

```bash
git -C .yia fetch
git -C .yia checkout "<NOUVEAU-COMMIT-VALIDÉ>"
git diff --submodule=log -- .yia
make version FORMAT=json
make validate
make update
make update
make doctor
```

Lire les notes de migration avant de valider le nouveau gitlink. Ne suivre une
branche distante ni modifier le code du sous-module comme mise à jour implicite.
