# U49 — Mettre à jour la connaissance avec `update-project-docs`

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Après une décision durable, demander `update-project-docs`. Le skill choisit le
document propriétaire, évite les doublons et actualise l'index. Relire le diff
et exclure secrets, informations temporaires et données déjà reconstructibles.
