# U33 — Supprimer volontairement les données

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Commencer par une sauvegarde U31 et arrêter toute écriture applicative. La
commande interactive affiche les volumes du projet puis exige de saisir
exactement son nom :

```bash
make destroy-data
```

Pour une automatisation explicitement destructive :

```bash
make destroy-data YES=1
```

Yia supprime d'abord les containers et le réseau, puis uniquement les volumes
portant les labels Compose du projet. Les volumes PostgreSQL, `vendor` et
`node_modules` ciblés sont irrécupérables par Yia ; `.yia-data/` reste conservé.
Cette commande n'est jamais appelée implicitement par une autre cible.
