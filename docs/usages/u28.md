# U28 — Partager PostgreSQL entre plusieurs applications

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

U24 et U25 déclarent une seule instance. Sur le réseau Compose, toutes les
applications utilisent l'adresse `postgres`, le port `5432`, ainsi que le nom
de base et l'utilisateur choisis dans `.env`. Aucun `localhost` ne doit être
utilisé depuis un container pour joindre PostgreSQL.

Yia ne copie pas automatiquement les identifiants PostgreSQL dans les services
applicatifs. Le projet transmet sa configuration métier par son propre
mécanisme, sans placer de secret dans `yia.yml` ni dans la documentation. Tester
la base depuis `SERVICE=postgres`; tester ensuite la connexion avec la commande
du framework depuis U15.
