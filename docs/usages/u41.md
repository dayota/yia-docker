# U41 — Tester un projet consommateur

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Dans un projet consommateur, `make test` valide que Yia peut charger la
configuration et ses dépendances déclaratives. Il ne découvre ni PHPUnit, ni
Pest, ni Vitest, ni les tests métier. Exécuter ceux-ci explicitement via U15 ou
U22. Dans le dépôt Yia lui-même, `make test` lance la suite Pytest du moteur.
