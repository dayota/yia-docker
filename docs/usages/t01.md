# T01 — Dépendance, Docker ou service indisponible

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

Symptômes : `make check-install` échoue, `YIA_DOCKER_UNAVAILABLE` apparaît ou
un healthcheck reste unhealthy. Exécuter, sans rien supprimer :

```bash
make check-install
make doctor FORMAT=json
make ps FORMAT=json
make logs
```

Un client absent se corrige avec U02 ou l'installation du système ; un daemon
inaccessible avec son démarrage ou les droits de l'utilisateur ; un seul
service unhealthy avec ses logs et sa configuration. Relancer `make update`,
puis `make doctor`. Ne pas arrêter un container étranger pour libérer une
ressource sans autorisation.
