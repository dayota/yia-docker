# U09 — Exposer une application Symfony en PHP 8.2

[← Index des cas d’usage](./index.md) · [Gestion du guide](../usages-management.md)

## Variante Symfony

Reprendre les fichiers et les commandes de U08, placer le contrôleur frontal
Symfony dans `apps/web/public/index.php`, puis utiliser :

```yaml
version: 1
project:
  name: symfony-web
environment:
  domain: symfony-web.localhost
applications:
  web:
    type: php
    path: apps/web
    runtime:
      php: "8.2"
    framework:
      name: symfony
      version: "7.4"
    web:
      hostname: symfony-web.localhost
      public_directory: public
```

```bash
make init
make update
curl --fail --resolve symfony-web.localhost:80:127.0.0.1 \
  http://symfony-web.localhost/
make exec SERVICE=web CMD="php --version"
```

Les services attendus sont `apache` et `php-8.2`; la dernière commande doit
annoncer PHP 8.2. Le nom de framework documente le projet mais Yia ne génère pas
Symfony. Les garanties de routage, de volume `vendor` et d'idempotence sont les
mêmes que pour U08.
