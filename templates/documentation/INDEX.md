# Index de documentation projet

## Architecture

### `architecture/development-environment.md`

**Description :** environnement de développement généré à partir de `yia.yml`.

**Lire lorsque :**

- une application ou un service est ajouté ;
- un runtime change ;
- la topologie de développement est modifiée.

## Décisions

### `decisions/README.md`

**Description :** rôle, organisation et statuts des décisions d'architecture.

**Lire lorsque :**

- une décision structurante doit être créée ou retrouvée ;
- plusieurs alternatives raisonnables existent ;
- la raison historique d'un choix est nécessaire.
