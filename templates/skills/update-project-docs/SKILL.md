# update-project-docs

Mettre à jour la connaissance durable du projet lorsqu'une tâche crée, modifie ou invalide une décision, une contrainte, une convention, une règle métier ou un élément d'architecture.

Toujours rechercher une documentation existante avant de créer un nouveau document.
Mettre à jour `INDEX.md` lorsque la découvrabilité change.
Ne pas documenter les éléments triviaux, temporaires ou secrets.
